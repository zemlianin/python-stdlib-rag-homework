# Data

## Источник

Источник данных — docstring модулей, классов и функций из локально установленной стандартной библиотеки Python. Эти тексты входят в исходный код Python и распространяются вместе с Python под Python Software Foundation License Version 2.

## Что индексируется

Индексируются только текстовые docstring. Для каждой записи сохраняются:

- `id` — внутренний идентификатор записи;
- `name` — имя модуля, класса или функции;
- `text` — текст для индексации;
- `source_file` — путь к исходному `.py` файлу;
- `source` — описание источника;
- `license` — лицензия источника.

## Масштаб

Скрипт `scripts/prepare_datasets.py` обычно извлекает больше 1000 записей. Это соответствует требованию для оценки «отлично» по масштабу данных. Точное число зависит от версии Python и набора файлов стандартной библиотеки.

## Почему эти данные подходят для RAG

Docstring являются короткими самостоятельными текстовыми фрагментами. Они хорошо подходят для учебного RAG, потому что вопрос пользователя можно сопоставить с описанием функции или модуля, а затем показать источник, `doc_id`, score и текст найденного фрагмента.
