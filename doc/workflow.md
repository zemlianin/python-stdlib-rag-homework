# Workflow

## Цикл одной итерации

Каждая итерация выполняется по схеме: сначала цель, затем код, затем проверка, затем фиксация результата. После успешной проверки обновляется `doc/tasklist.md`.

## Что делать до кода

Перед написанием кода нужно понять входной файл, выходной файл и критерий проверки. Если итерация меняет формат данных, этот формат фиксируется в README или документах.

## Как выполнять проверку

Для каждой итерации есть отдельная команда проверки. Если команда не проходит, следующая итерация не начинается. Основная финальная проверка:

```bash
uv run python scripts/build_index.py
uv run pytest tests/ -v
uv run python scripts/check_generator.py
```

## Когда обновлять tasklist

`doc/tasklist.md` обновляется после того, как итерация работает локально и есть понятный результат.

## Правила коммита

Коммиты делаются небольшими шагами: scaffold, data, ingestion, chunking, index, retrieval, generator, UI, tests/readme. В коммит не нужно добавлять `.venv`, кеши и сгенерированные файлы индекса.

## Запрещенные действия

Нельзя отвечать без источников, скрывать ошибки запуска, добавлять платные API как обязательную зависимость, коммитить секреты и делать UI, который не показывает найденные фрагменты.
