# Project Idea

## Проблема

В стандартной библиотеке Python много модулей, классов и функций. Новичку трудно быстро понять, где искать нужную возможность и какой объект за что отвечает. Обычный поиск по файлам требует знания точных названий, а документация не всегда сразу дает короткий ответ с источником.

## Цель проекта

Сделать учебный RAG, который ищет по текстовым docstring стандартной библиотеки Python и показывает ответ вместе с найденными источниками. Проект повторяет pipeline из учебного репозитория: подготовка данных, ingestion, chunking, построение TF-IDF индекса, retrieval, demo-answer и Streamlit UI.

## Для кого проект

Проект рассчитан на студентов и начинающих Python-разработчиков, которым нужно быстро находить объяснения по стандартной библиотеке Python.

## Какие данные используются

Источник данных — docstring модулей, классов и функций из локально установленной стандартной библиотеки Python. Данные извлекаются скриптом `scripts/prepare_datasets.py` через модуль `ast`. Обычно получается больше 1000 текстовых записей. На моей машине было извлечено более 5000 записей.

## Критерий успеха

Проект считается успешным, если команда `uv run python scripts/build_index.py` создает индекс, Streamlit показывает ответ и источники, 3 demo-вопроса возвращают релевантные фрагменты, negative-вопрос дает отказ без выдумок, а тесты проходят зеленым статусом.
